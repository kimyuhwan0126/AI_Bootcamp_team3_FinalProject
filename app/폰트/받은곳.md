# Spoqa Han Sans Neo — 이 폴더의 woff2 는 어디서 왔나

앱 전체가 쓰는 본문 글꼴이다. 사람이 정했다(2026-08-20).

## 받은 곳

```
https://cdn.jsdelivr.net/gh/spoqa/spoqa-han-sans@latest/Subset/SpoqaHanSansNeo/
```

`Subset/` 쪽이다 — 같은 저장소의 비-Subset 판은 쓰이지 않는 글리프까지 담아 훨씬 무겁다.
라이선스 원문(`LICENSE`)은 저장소 뿌리에서 받았다:
`https://raw.githubusercontent.com/spoqa/spoqa-han-sans/master/LICENSE`

다시 받아야 하면 이 세 줄이면 된다.

```bash
base=https://cdn.jsdelivr.net/gh/spoqa/spoqa-han-sans@latest/Subset/SpoqaHanSansNeo
for w in Regular Medium Bold; do curl -sSfo "SpoqaHanSansNeo-$w.woff2" "$base/SpoqaHanSansNeo-$w.woff2"; done
curl -sSfo LICENSE https://raw.githubusercontent.com/spoqa/spoqa-han-sans/master/LICENSE
```

## 왜 세 벌뿐인가

이 글꼴이 내주는 무게는 100 · 300 · 400 · 500 · 700 다섯이다. 그중 셋만 받는다.

| 받은 것 | 쓰는 자리 |
|---|---|
| 400 Regular | 본문 |
| 500 Medium | 보조 글씨 · 안 고른 탭 |
| 700 Bold | 강조 — 전부 |

100·300 은 이 앱에 400 보다 얇은 글씨가 한 자리도 없어서 안 받는다. 한 벌이 180KB 니
안 쓰는 것을 받아 두면 저장소만 무거워진다.

## ⚠ 700 이 이 글꼴의 끝이다

`font-weight: 800` · `900` 을 쓰면 브라우저가 **가짜 굵게**(synthetic bold)를 그려 획이
뭉갠다. 그래서 2026-08-20 에 앱 전체의 800·900 을 700 으로 내리고, 두 무게로 강약을
만들던 짝은 약한 쪽을 500 으로 내렸다(`app/globals.css` 의 `--font-sans` 머리말).

**새 CSS 를 쓸 때 800 이상을 적지 마라.** 굵기를 더 주고 싶으면 크기나 색으로 말한다.

## 왜 `public/` 이 아니라 `app/` 안인가

`next/font/local` 이 빌드 때 이 파일을 읽어 해시 붙인 이름으로 스스로 내보낸다
(`app/layout.tsx`). 정적 폴더에 둘 필요가 없고, 두면 오히려 두 벌이 나간다.
이 폴더에 `page.tsx` 가 없으므로 Next 는 여기를 길(route)로 삼지 않는다.
