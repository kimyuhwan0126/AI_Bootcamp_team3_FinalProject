### 3-2. 추천 알고리즘 — 구조만 있고 알맹이가 없다

**현재 점수식은 이것뿐이다** (`lib/scoring/fairness.ts`):

```
score = 최대이동시간 + 편차 × 0.8   → 낮은 순 3개
```

상권·환승·요금·모임 성격 **전부 미반영**.

- **수도권 안**: 후보 풀이 하드코딩이다. 결과가 괜찮아 보이는 건 알고리즘이 아니라
  **사람이 미리 골라둔 큐레이션** 덕분이다 — 이건 숨길 일이 아니라 이 앱이 동작하는 방식이다.
- **수도권 밖**: ✅ **해결됨 (PR #26 머지 완료 — `dcb820a`)**. 거점 풀을
  **12곳 → 28곳(전국)** 으로 넓혔다. 예전에는 12곳 중 가장 가까운 곳도 45km 를 넘으면
  `geometricCandidates()`(순수 기하 폴백)로 빠져 `옥천군 안남면 도덕리` 같은
  **모일 수 없는 좌표**가 확정되고, 거기서 존재하지 않는 mock 가게가 떴다.

**실행으로 확인한 before/after** (`lib/geo.ts` 의 `recommendRegions` 직접 호출):

| 조합 | before | after |
|---|---|---|
| 서울+부산 | 중간지점 3 / 4 / 2 | **대전역 / 청주 / 동대구역** |
| 서울+거제 | 중간지점 3 / 4 / 2 | **전주역 / 대전역 / 청주** |
| 대구 2인 | 중간지점 3 / 2 / 4 | **동대구역** (1곳) |
| 서울 3인(대조군) | 왕십리 / 종로3가 / 사당 | **왕십리 / 종로3가 / 사당** (동일 — 회귀 없음) |

곁들여 바꾼 값 두 개(둘 다 팀 결정):
- `HUB_COVER_KM` **45 → 55** — 거점을 넣어도 서울+부산은 여전히 폴백이었다.
  중심이 경북 내륙 공백지대라 최근접 대전역이 55km 였다. 45km 면 장거리 7조합 중
  4개만 정상, **55km 면 7/7**. 45 는 후보가 수도권 12곳뿐이던 시절의 값이다
- `FALLBACK_MAX_KM = 60` **신설** — "가까운 순 4곳 강제 확보"가 대구 2인 모임에
  창원·울산(각 72km)을 끌어와 후보 2·3위로 띄웠다. 💰 이동시간 API 도 후보 수만큼 쓴다

⚠️ **후보 이름은 나아졌지만 이동시간 숫자는 아직 거리 추정이다** — 위 표의 분 단위 값은
`estMinutes`(직선거리 모델)라 서울↔부산이 949분으로 나온다. 실 ODsay 경로로는 130분대다

`"포항시청"` 이 `"시청"`(서울시청)에 매칭된다. 카카오 키가 없을 때만 타는 경로라

#### 🔴 남은 문제 — 지방 거점 밀도 (통합 세션이 PR #26 검토 중 발견)

`lib/geo.ts` 로직을 그대로 떼어 계산한 **후보 개수 시뮬레이션**이다.
PR #26 본문은 대구만 언급했지만, **같은 원인이 부산·광주에도 나타난다**:

| 조합 | 후보 | 내용 |
|---|---|---|
| 서울 3인 | 9곳 | 강남역·교대·왕십리… + `서울역` |
| 서울+부산 | 3곳 | 대전역(55) · 청주(60) · 동대구역(72) ✅ |
| 부산 2인 | 4곳 | 서면·부산역 + **창원(35km)·울산(51km)** |
| 광주 2인 | **2곳** | 광주송정역 + **목포역(56km)** |
| 대구 2인 | **1곳** | 동대구역 |

**원인은 `FALLBACK_MAX_KM` 값이 아니라 거점 밀도다.** 수도권은 14곳인데 지방
대도시는 **1곳뿐**이라, 허용반경 안에 3곳이 안 차서 "가까운 순 확보" 폴백이
발동하고 옆 도시를 끌어온다. **상한을 올리면 더 먼 도시가 오고, 내리면 대구처럼
1곳이 된다 — 어느 값도 정답이 아니다.**

→ **해결 방향(팀 결정 사항)**: 지방 대도시에 도심 거점을 2~3곳씩 추가.
   예: 대구 = 동대구역 + 반월당/동성로 · 광주 = 송정역 + 상무지구/충장로 ·
   부산 = 서면 + 부산역 + 해운대. 그러면 폴백 자체가 안 걸려 옆 도시가 안 끌려온다.

⚠️ **후보가 1곳이면 "3개 중 투표"라는 이 앱의 핵심 UX 가 성립하지 않는다.**
`recommendRegions` 는 `slice(0,3)` 이라 1곳이면 1개만 내려가고, 화면에 `regions.length`
분기가 없어 투표 항목이 하나만 뜬다(크래시는 아님, **미검증** — CI 스모크는
수도권 케이스만 돈다). 거점 밀도를 보강하면 자연히 해소되므로 화면 처리보다
밀도 보강을 먼저 본다.

## 4. 겪은 사고 (반복 금지)

### 타입검사·빌드로 안 잡히는 것

| 사고 | 왜 안 잡히나 |
|---|---|
| `useEffect` 를 조건부 `return` 뒤에 배치 | 화면이 통째로 미렌더. `tsc`·`build` 둘 다 통과 |
| `lib/store.ts` 호출에 `await` 누락 | Promise 를 그냥 둬도 타입이 맞다 — 조용히 무동작 |
| 모달 prop 어긋남 | 조건부 렌더라 열어보기 전엔 모른다 |

→ **브라우저로 실제로 열어야 잡힌다.** 그래서 CI 가 크로미움을 띄운다.
→ 훅 배치 사고는 이제 `npm run lint` 가 잡는다(`react-hooks/rules-of-hooks`).

### `backdrop-filter` 안에서는 `position: fixed` 가 갇힌다

`.appbar` · `.leaderbar` · `.v8-bottomnav` · `.v8-header` 가 전부 쓴다.
그 안에서 전체화면 오버레이를 띄우면 헤더 안에 갇혀 잘린다 —
**반드시 `createPortal(…, document.body)`** (`components/v8/LoginSheet.tsx` 참고).

### 내 환경에서만 되는 것

`npm run verify` 가 **방금 clone 한 환경에서 스모크 3/4 실패**했다
(`Executable doesn't exist` — Playwright 브라우저 없음). 개발 컨테이너엔
`PW_CHROMIUM_PATH` 가 있어서 안 보였다. **팀원 환경을 재현해서야 드러났다.**
→ `pretest:smoke` 로 자동 설치. **"내 환경에서 되는지"가 아니라 "빈 환경에서 되는지"를 본다.**

### 문서가 코드와 어긋나면 다음 세션이 잘못된 전제로 시작한다

v8 에서 `CLAUDE.md` 에 쓰지도 않는 Tailwind·shadcn 이 적혀 있었다.
이번 감사에서도 나왔다 — 없는 파일(`ChatSection.tsx`)을 `CODEOWNERS` 가 가리켰고,
그대로 뒀으면 **GitHub 이 그 줄을 조용히 무시**해 소유권이 안 걸렸을 것이다.
