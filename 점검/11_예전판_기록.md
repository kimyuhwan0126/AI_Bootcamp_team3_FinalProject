## 2. 머리말 세 단추

셋 다 `app/components/v8/V8Header.tsx` 에 있다. 앞의 둘은 `guard(주소)` 를 거친다 —
**세션이 없으면 그 자리에서 로그인 시트**를 띄우고, 로그인한 뒤 원래 가려던 곳으로 보낸다.

| 단추 | 로그인 안 했을 때 | 로그인했을 때 | 사진 |
|---|---|---|---|
| `＋` (모임 생성) | 로그인 시트 | `/meetings?open=create` — 모임 탭 + 만들기 모달 | `예전판_03_머리말_더하기.png` |
| `→` (모임 참가) | 로그인 시트 | `/meetings?open=join` — 모임 탭 + 참여 모달 | `예전판_04_머리말_입장.png` |
| `🔔` (알림) | 제자리 팝오버 | 같음 | `예전판_05_머리말_알림.png` |

- `→` 단추에는 로그인 상태 배지가 붙는다 — 카카오면 `K`, 임시 로그인이면 **이름 첫 글자**
  (사진 `예전판_11_목록_카드5개.png` 오른쪽 위의 파란 `점`).
- **알림 팝오버**: `알림` / "아직 받은 알림이 없어요." / "로그인하면 내 모임 알림을 받을 수 있어요."
  / `[로그인]`. 로그인한 상태면 마지막 줄이 `이름님 · 임시 로그인` + `[로그아웃]` 으로 바뀐다.
  **실제 알림 발송은 아예 없다** — 가짜 알림을 채우지 않고 빈 상태만 보여 준다(코드 주석에도 그렇게 적혀 있다).

### 로그인 시트 (`LoginSheet.tsx`) — ⑩번 물음

- 제목 `로그인` / "가입하지 않아도, 이름만 있으면 모임을 만들고 투표할 수 있어요."
- `이름 (닉네임)` 칸 + **[이름으로 시작하기]** → `lib/session.ts` 가 `localStorage["moimer:session"]` 에
  `{kind:'guest', name, tempKey}` 를 쓴다. **서버에 안 간다.**
- 아래 `또는` 줄 다음에 노란 **[카카오로 로그인]** — `href="/api/auth/kakao"`
- **주소만 확인했다(누르지 않았다)**: `GET /api/auth/kakao` → `307` → `https://kauth.kakao.com/oauth/authorize`
- 돌아오는 길: `/api/auth/kakao/callback` → 토큰 교환 → `/?name=<닉네임>&kakao=1` 로 홈에 되돌린다.
  홈(`app/page.tsx:136`)이 그 `name` 을 보고 `loginAsKakao()` 로 **localStorage 세션**을 만든다.
  → **서버 세션도 쿠키도 없다.** 카카오는 닉네임을 얻는 데만 쓰이고, 그다음은 임시 로그인과 똑같다.
- 실패하면 `/?err=login&step=…&detail=…` 로 돌아와 홈이 그 사유를 **영문 그대로** 찍는다
  (`app/page.tsx:150` — 지금 말투 규칙 위반이다).

- [만들기] → 지금은 **500** (0장 참고). 정상일 때는 요약 모달로 바뀌어
  `모임 이름 · 모임 코드 · 정원 · 방장 · 모임 시간 · 홈에서 가져옴` 을 보이고

## 4. 목록 카드에 무엇이 적히나 (`예전판_11_목록_카드5개.png`)

카드 한 장은 `제목` 한 줄 + `i-sub` 한 줄 + 오른쪽 `›` 다. 누르면 `/m/<코드>`.

```
{상태 문구} · {D-day} · {N}명 · {확정된 곳}
```

실제로 나온 것:

| 카드 | 아래 줄 |
|---|---|
| 가짜② 지역단계 | `장소 정하는 중 · D-DAY · 4명` |
| 가짜③ 지점단계 | `장소 정하는 중 · D-1 · 5명 · 성수동2가` |
| 가짜① 모집단계 | `지역 정하는 중 · D-3 · 2명` |
| 가짜④ 확정 | `확정 완료 · D-7 · 6명 · 황소곱창` |
| 가짜⑤ 지난모임 | `지난 모임 · 6명 · 온기족발` |

- 진행 중이면 아래 줄이 **파란 굵은 글씨**, 확정·지난 모임이면 회색이다. 지난 모임은 카드가 65% 로 흐려진다.
- **D-day 는 시간을 정한 모임만** 나온다. 지난 모임에는 아예 안 나온다.
- 곳 이름은 지점이 있으면 지점, 없으면 지역을 쓴다.
- 정렬: 가까운 모임이 위. 시간 안 정한 모임은 맨 아래. 지난 모임 탭만 최근에 끝난 것부터.
- **역할(방장/참여)은 카드에 안 적힌다** — 거르개로만 갈린다.

### 목록 위에 붙는 노란 '투표하세요' 띠

지금 고를 게 열려 있는 모임을 **최대 3개** 목록 위에 따로 붙인다.
`🔔 투표하세요! — {모임 이름}` / `{지역|지점} 투표 진행 중 · N명 · 지도를 누르면 한 표`.

### ⚠️ 여기서 찾은 어긋남 둘

1. **칩 이름과 카드 문구가 서로 다르다.** 거르개 `모집` 으로 걸러진 모임의 카드에는
   `지역 정하는 중` 이라 적히고, 거르개 `지역` 으로 걸러진 모임의 카드에는 `장소 정하는 중` 이라 적힌다.
   `stageKey()`(meetings/page.tsx:292)와 `STAGE_LABEL`(같은 파일 56줄)이 **다른 기준**을 쓴다.
2. 지난 모임 카드에 **언제 만났는지가 없다** — 시간 줄이 통째로 빠진다(논의109 가 고치라고 한 바로 그것).

## 5. 거르개가 실제로 어떻게 걸러 내나

두 줄이다. 윗줄 `상태`(전체·모집·지역·지점·확정·지난), 아랫줄 `역할`(방장·참여).
**한 번에 하나만** 켜진다 — 상태와 역할을 겹쳐 걸 수 없다.

| 누른 칩 | 걸러 낸 규칙 | 실제 결과 | 사진 |
|---|---|---|---|
| 전체 | 지난 모임을 뺀 전부 | ②③①④ | `예전판_12_거르개_전체.png` |
| 모집 | `stage=main` (`aiPhase≠place`) | ① | `…_모집.png` |
| 지역 | `stage=chat` + `aiPhase=region` | ② | `…_지역.png` |
| 지점 | `aiPhase=place` | ③ | `…_지점.png` |
| 확정 | `stage=result` | ④ | `…_확정.png` |
| 지난 | `isPast` | ⑤ | `…_지난.png` |
| 방장 | 지난 것 빼고, 이 기기에 방장 신원이 있는 것 | ③① | `…_방장.png` |
| 참여 | 지난 것 빼고, 방장이 아닌 것 | ②④ | `…_참여.png` |

- 이름 검색칸은 거르개보다 **먼저** 걸린다(둘이 겹쳐 걸린다).
- 결과가 0개면 `해당하는 모임이 없어요.` — 지난 모임 탭에서만 `지난 모임이 없어요.`
  **모임이 정말 0개일 때와 같은 말을 한다**(논의78·119 가 갈라 놓으라고 한 자리).
- 역할 판정은 **서버가 아니라 이 기기의 localStorage** 를 본다(`getIdentities(code)`).
  기기를 바꾸면 내가 만든 모임도 '참여' 로 보인다.

| 내 저장 위치 | "모임을 **만들 때** 바로 불러와요" | 모임 안 출발지 폼의 `내 저장 위치` 칩(`OriginForm.tsx:85`) · 링크로 들어온 사람의 출발지 첫 값(`JoinGate.tsx:67`) | ❌ **안 온다** |
| 애용 이동수단 | "**새로 만드는 모임**에 이 이동수단이 기본으로 적용돼요" | 홈 화면의 기본 이동수단(`app/page.tsx:131`) · 모임 안 출발지 폼의 기본값(아직 등록 전일 때만) | ❌ **안 온다** |
| 기본 PIN | "참여 폼에 자동으로 채워진다" | **모임 참여 모달의 PIN 칸** (`meetings/page.tsx:136`) | 해당 없음 |

- 확인한 것: 만들기 모달을 열어 `저장 위치|강남역|홍대입구|이동` 을 찾아봤다 → **없다**
  (`예전판_15_만들기폼_저장위치없음.png`). 만들기 폼에는 출발지 칸 자체가 없으니 넣을 자리가 없다.
- 참여 모달을 열면 PIN 칸에 **`7391` 이 이미 들어 있다** (`예전판_16_참여폼_PIN자동채움.png`). 이건 약속대로 된다.
- 즉 **"모임을 만들 때 바로 불러와요" 와 "새로 만드는 모임에 기본으로 적용돼요" 는 둘 다 거짓말이다.**
  `MeetingClient.tsx:254` 주석에 "CEO 보고" 로 한 번 지적됐고 **모임 안쪽만** 이어 붙였다 — 문구는 안 고쳤다.

### 그 밖에 `/me` 에 있는 것

- 맨 위 프로필 줄: `비회원` / `임시 로그인 (이 기기에만 저장)` / `카카오 로그인됨`.
  비회원이면 `[로그인]`, 임시 로그인이면 노란 `[카카오로 전환]`(→ `/api/auth/kakao`).
- `스케줄 가져오기` — `[구글 캘린더에서 가져오기 (준비 중)]` 꺼진 단추 하나. 기능 없음.
- `계정` — 로그아웃. "로그아웃하면 이 기기의 임시 키가 즉시 삭제돼요."
- PIN 칸 밑에 **"⚠️ 이 기기에만 저장돼요(localStorage)"** 라고 정직하게 적혀 있다.

## 8. `/members` · `/votes` 는 무엇인가

**둘 다 죽은 주소다.** 파일이 리다이렉트 한 줄만 남아 있다.

| 주소 | 무엇이었나 | 지금 |
|---|---|---|
| `/members` | '모임원' 탭 — 참여자 현황·도착 신호등 | `→ /meetings` (실측 확인) |
| `/votes` | '투표함' 탭 — 지금 고를 것 모음 | `→ /meetings` (실측 확인) |

탭바가 v6 에서 **5 → 3** 으로 줄면서 둘을 모임 탭으로 합쳤다.
파일을 안 지운 까닭이 코드 주석에 있다 — *"카카오톡에 공유된 옛 링크·북마크가 404 로 죽지 않게"*.
`BottomNav.tsx` 의 `V8Tab` 타입에도 `votes`·`members` 가 남아 있지만 탭바에는 안 그린다.

그 자리에 있던 것들은 지금 모임 안 화면에 있다:
참여자 현황 → `sections/ParticipantList`, 도착 신호등 → `sections/ArrivalPanel`,
고를 것 → 모임 탭 위쪽 노란 띠.

## 9. 모임 안 화면 `/m/<코드>`

한 화면에 **머리말 · 단계 아이콘 · 지도 · 카드 여러 장 · 아래 막대** 가 세로로 쭉 이어진다.
시트가 아니라 **그냥 스크롤**이다.

### 공통 뼈대

- 머리말(`.appbar`): `←` · 모임 이름 · `코드 XXXXXX · 정원 8명 · N명 참여` · 오른쪽에 역할 알약
  (`👑 방장` / `🙋 참가자` / `👀 구경 중`)
- 단계 아이콘(`.stepicons`): **`거점 투표 ─ 가게 투표 ─ 최종 확정`** 동그라미 셋
- 지도(`.map`, 카카오맵): 참여자 핀에 **번호+이름**, 후보 핀에 **이름+N표**.
  `내 위치 보기` / `전체 위치 보기` / `⛶` / 안내 알약
- 맨 아래: 방장이면 `.leaderbar`(누를 수 있는 단추들), 참여자면 `.ParticipantBar`(글자만).
  그 아래 탭바 `홈·모임·내정보` 가 **모임 안에서도 계속 보인다.**

### 단계별로 무엇이 보이나

**① 지역 단계 · 방장** (`예전판_19_모임_지역단계_방장.png`)
`1. 메인 · 내 출발지` 카드(내 저장 위치 칩 · 이동 수단 · [출발지 수정]) →
`참여자 현황` 카드(`3/3 출발지 등록` · `3/8명 · 5자리 남음` · 사람마다 [내보내기]) →
`2. 지역 정하기 / 어디쯤에서 볼까요? / 0/3명 · 후보 2/5` 카드(후보마다 `최대 32분 · 편차 6분` · [지우기] · [후보]) →
"0/3명이 찍었어요. 다 안 찍어도 방장이 확정할 수 있어요." → `＋ 다른 후보 등록` · `✍ 다른 후보로 확정`.
아래 막대: `🤖 추천 지역 3곳` · `0/3명 찍음 · 0표 / 📍 '성수동2가' 로 정하기`

**② 지역 단계 · 참여자** (`예전판_23_모임_지역단계_참여자.png`)
같은데 [지우기]·[내보내기]·`✍ 다른 후보로 확정` 이 없고, 아래 막대가 글자다 —
`지역 정하는 중 · 후보 2개 / 지도를 눌러 주세요 — 누른 곳이 곧 내 한 표예요`

**③ 지점 단계 · 방장** (`예전판_20_모임_지점단계_방장.png`)
지도 위에 빨간 알약 `중간 추천 지역 · 성수동2가`.
`2. 투표 · 2차 가게 / 성수동2가에서 어디로? / 2/3명 투표` 카드 —
줄마다 `🍖 황소곱창` `최다` `점검봇 등록` / `2표 · 음식점 · 220m` / 오른쪽에 `[투표함 ✓]` 또는 `[투표]`.
`참가자별 이동시간` 카드(사람마다 `~ 조금 멀어요 / 경로 기준 / 28분 / 🚇 대중교통 · 경로 상세 ›`).
아래 막대: `← 이전 단계` · `2/3명 · 미투표 민준 / 지금 확정 · '황소곱창'`

**④ 결과 · 방장** (`예전판_21_모임_결과_방장.png`)
`🎉 3. 결과 · 추천장소 확정` · `🍖 황소곱창` · `성수동2가 · 음식점 · 220m` ·
`🗳️ 투표로 함께 정했어요` · `🍽 메뉴 · 사진 · 리뷰 보기` →
`참여자 3명 · 이동시간` → `🗺 카카오맵에서 황소곱창 열기` +
"길찾기·메뉴·전화는 카카오맵에서 확인하세요. 예약·결제는 모이머가 대신하지 않아요." →
`도착 신호등`(`D-3 · 8. 16. 오후 02:20` · "모임 당일에 열려요") →
`부가기능`(📅 Google 캘린더 · 📄 .ics · 💬 카카오톡 알리기 · 🔗 링크 복사) →
**`위험 구역`**(🗑 모임 삭제 — "참여자·후보·표가 전부 사라지고 되돌릴 수 없어요") →
`후보부터 다시 [🔄 되돌리기]` · `표만 초기화 [🗳️ 재투표]`

**⑤ 지난 모임** (`예전판_22_모임_지난모임.png`)
결과 화면 그대로에 `지난 모임 / 종료됨` 카드가 붙는다 —
"기록 열람만 돼요. 되살릴 수는 없고, 같은 멤버로 새 모임을 만들 수 있어요." +
**[🔁 이 멤버로 재모임 만들기]** ("카카오 로그인한 멤버는 자동으로 옮겨가고, 그 외에는 새 초대 링크로 다시 참여해요").
`위험 구역`·`되돌리기`·`재투표` 는 사라진다. **모임 삭제도 같이 사라진다.**

**⑥ 링크만 받은 사람** (`예전판_18_모임_링크만받은사람.png`)
역할 알약이 `👀 구경 중`. 참여자 이름·출발지·후보·표가 **다 보인다**.
`아직 참여 전 / 구경 중이에요 / 위 지도에서 만나고 싶은 곳을 눌러 보세요.
누르면 이름·출발지를 물어보고 참여까지 한 번에 끝나요.` + `[🙋 나도 참여]`

**⑦ 없는 모임** (`예전판_26_없는모임.png`)
`🔍 / 모임을 찾을 수 없어요 / 코드 ZZZZ99 의 모임이 없어요. / [홈으로]`
