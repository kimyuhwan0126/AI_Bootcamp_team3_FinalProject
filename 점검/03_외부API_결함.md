# 외부 API·폴백·오류 전수 조사 (에이전트 3) — 2026-08-11

## 가장 중요한 발견 — quota 문구가 화면에 도달하지 못한다

| 경로 | 서버가 내는 것 | 사용자가 실제로 보는 것 |
|---|---|---|
| `/api/places` 429 | `quota_kakao` | **영문 코드 `quota_kakao` 가 토스트에 그대로** |
| `/api/places/search` 429 | `quota_kakao` | **"찾는 곳이 없어요"** — 한도 초과인데 없다고 거짓말 |
| `send()` 번역표 | — | `POST /api/m/[code]` 는 quota 를 **절대 반환하지 않는다** |
| ODsay | — | **호출 코드가 app-v2 에 아예 없다 — 죽은 문구** |

→ 그릴링 원장 #379~381 "고칠 수 있는 사람에게만 원인을" 규칙이 **실행 경로가 없어 한 번도 발동하지 않는다.**

## 치명

| # | 결함 |
|---|---|
| 1 | **Nominatim 초당 1회가 동시 요청에서 무력화** — 10개 동시 → 1개 즉시 + 9개가 1.1초 뒤 **동시** 발사 (각자 재고 각자 잔다) |

| 4 | **AI 가 성공하면 환각을 검증 없이 후보로 등록** — 실재·좌표범위·확정지역 반경 검사 전무 |

## 높음
5. `quota_kakao` 가 번역 안 된 영문으로 토스트에 표시
6. 검색 429 → "찾는 곳이 없어요" 로 둔갑. 출발지 필수라 **참여 자체가 막히는데 이유를 모른다**
7. `quota_odsay` 는 완전한 죽은 문구
8. **"실패"와 "결과 없음"이 구별되지 않는다** — 양쪽 죽어도 `[]` 200
9. 국외 좌표가 안 막힘 (geo 의 Nominatim 에 `countrycodes=kr` 없음)
10. `/api/geo`·`/api/places` 에 인증·레이트리밋 없음 → 외부에서 카카오 한도 소진 가능
11. **모든 catch 가 빈 블록** — 401(키 만료)과 "결과 없음"이 로그에서 동일

## 중간
12. 파라미터 누락이 (0,0) 으로 통과 → 대서양 좌표로 실호출
13. geo_cache upsert 가 region_code·source 미갱신 → 캐시 오염
14. 실패가 캐시 안 됨 → 바다 연타가 매번 외부를 태움
15. DB 예외 방어 없음 → 500
16. 카카오 카테고리 4회 중 하나 실패 시 앞의 결과를 통째로 버림
17. 429 는 폴백하지 않음
18. AI 후보가 방장의 표로 계산됨
19. 서버 `case 'ping'` 에 좌표·이름 검증 없음 (반경도 클라이언트에만)
20. `ai.ts` 가 `OLLAMA_FALLBACK_*` 를 안 씀 — 2순위 자동 전환 미구현
21. radius 미검증 → Overpass 초대형 쿼리 가능
22. SSE 실패를 화면이 모름 (`es.onerror` 없음, 폴링 폴백 없음, `X-Accel-Buffering` 없음)

## 구조 문제
외부 URL 3개가 하드코딩 + 실패 주입점 없음 + `geo.ts`/`db.ts` 가 모듈 로드 시 `neon()` 호출
→ 지금 상태로는 위 항목의 **80% 가 자동화 불가**.
우선 (1) `*_BASE` 환경변수 override (2) `fetch` 래퍼로 timeout·로깅 일원화 (3) 반환 타입에 `'down'` 상태 추가
