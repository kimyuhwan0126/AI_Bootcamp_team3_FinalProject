> 각 스킬은 독립 `.md` 파일. 필요 시 에이전트가 참조.

## 사용 방법
- 에이전트에게 작업 위임 시 해당 스킬 파일을 맥락으로 제공
- 스킬은 팀이 정의하고, AI가 실행 보조 (AI-GUIDE.md §3 매트릭스 참조)

## 메모
- 새 스킬 추가 시 이 인덱스에 행을 추가한다. 실제 `.md` 파일이 생성된 것만 등록한다.
