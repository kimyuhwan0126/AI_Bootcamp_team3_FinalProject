# SyncSpot — AI 개발 상세 가이드 (AI-GUIDE.md)

> `CLAUDE.md`의 상세판. 팀 전원이 AI를 일관되게 활용하기 위한 규칙.
> 대상: SyncSpot MVP — 일정은 시작 단계에서 확정하기 어려워 킥오프 시 별도 확정한다.

---

## 1. 이 가이드의 목적
- 팀이 **Claude Code를 동일한 방식**으로 쓰도록 통일 (인원·역할 배정은 확정 전까지 참고용 — 최신안은 **1인 4영역 FE/BE/Admin/Agent**, 본 문서 §4의 5역할은 초기 기획 문서 기반 **제안**)
- **AI가 만든 것 / 팀이 만든 것 경계** 명확화 → 책임 소재 & 데모 발표 대비
- AI 활용으로 **모든 팀원이 가치 있는 산출물**을 내도록 지원

### Claude Code 사용 패턴 (팀 표준)
- 작업 전: "이 작업은 CLAUDE.md/AI-GUIDE.md 몇 절 기준" 처럼 **근거 문서 명시**
- 작업 후: 변경된 파일 + smoke test 결과를 같이 보고
- 자연어 요청 예: "프로토타입의 빈 상태를 폼 컴포넌트로 바꿔줘"
- 코드 변경은 **PR 단위** + 리뷰어 지정

### 원칙 3줄
1. **판단(비즈니스/디자인/데이터)은 팀이, 생성은 AI가.**
2. **AI 산출물은 커밋 전 팀 리뷰를 거치는 걸 권장.**
3. **AI가 만든 코드는 PR에 `🤖 Generated with Claude Code` 표시.**

## 4. 역할별 AI 활용 가이드

> ⚠️ 아래 5역할(FE/BE/AI/QA·데이터/디자인·콘텐츠)은 초기 기획 문서 기반 **제안 배정**. 최신 계획은 **1인 4영역(FE/BE/Admin/Agent)** 기준이므로, 실제 역할 매핑은 확정 전까지 참고용. 아래 내용은 역할별 AI 활용 **패턴 참고용**.

### FE 리드
- 컴포넌트 마이그레이션: 프로토타입 HTML → Next.js + shadcn/ui 변환을 AI에게 위임
- 디자인 토큰은 디자인 확정 후 CLAUDE.md §3 반영 (현재 미정)
- Zustand store 설계는 AI 초안 → 리뷰

### BE/API 리드
- API Routes/Supabase RLS는 AI 초안 → 보안 검토(키 클라이언트 노출 지양, .env)
- 외부 API 장애 시 **mock fallback**을 AI에게 함께 작성 요청
- Realtime 동시성: DB unique constraint + 낙관적 업데이트

### AI/알고리즘
- Gemini 프롬프트는 **JSON schema 적용** + retry 1회 + 실패 시 수동 폴백
- ODsay 응답 캐싱 (Redis 또는 Supabase 캐시 테이블)
- 추천 가중치는 관리자 설정에서 즉시 반영

### QA·데이터 — AI 활용 많이 (제안 역할, 확정 전)
- **자연어로 AI에게**: "데모 시나리오를 AI-GUIDE §7 기준으로 써줘"
- smoke test 체크리스트 실행 → 버그 리포트 (AI가 이슈 템플릿 생성)
- seed 데이터: AI가 더미 JSON 생성 → 팀이 현실성 검토
- 네이버 예약 링크: 3개 가게 모바일 이동 유효성 **직접** 검증 (AI 불가)

### 디자인·콘텐츠 — AI 활용 많이 (제안 역할, 확정 전)
- UI 폴리싱: 프로토타입 HTML을 shadcn/ui 컴포넌트로 변환 요청 (컬러는 디자인 확정 후)
- 가게 카테고리 키워드 조사 → Kakao Search 쿼리 설계 입력값
- 카톡 공유 카드 문구: AI 후보 3개 → 팀 선택
- 문서/회의록: AI 초안 → 정리

## 6. 검증 방법론 (3관점)
모든 변경은 아래 3관점으로 확인:
1. **눈으로 확인** — UI 의도대로 렌더링?
2. **버튼으로 확인** — 클릭/플로우 정상?
3. **로그로 확인** — 콘솔/네트워크/Supabase 로그 정상?

## 9. 위험 & 대응 (상세)
| 위험 | 영향 | 대응 |
|---|---|---|
| API 키 미발급 | 중 | mock 우선, 키 확보 후 교체 |
| ODsay 장애 | 높 | 캐싱 + 수동 거점 + mock 3개 |
| Gemini 불안정 | 중 | JSON schema + retry 1 + 수동 입력 |
| 카톡 웹뷰 OAuth | 중 | 외부 브라우저 fallback 안내 |
| 스코프 크리프 | 중 | Scope Freeze 유지, 안내 에이전트는 안정화로 |
| 동시 투표 정합성 | 중 | Realtime + unique constraint |
| 역할별 작업 지연 | 중 | 임계경로 배정 명확화 + 구조화 지원 |
